Приватный сервис

Как устроено

Браузер → HTTPS → сервис: ключ, лимиты, очередь → Ollama на этом же сервере → модель. Ollama слушает только 127.0.0.1 — снаружи до модели можно дойти лишь через сервис.

Ограничения

    HTTP API

    POST /api/chat — переписка {"messages": [{"role", "content"}], "stream"}, GET /api/status — модель, сервер, лимиты, очередь. Заголовок — Authorization: Bearer <ключ>.
